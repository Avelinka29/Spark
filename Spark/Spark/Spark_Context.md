# Spark — текущее состояние проекта

## Концепция

Spark — цифровая экосистема развития молодёжи Беларуси. Приложение помогает находить возможности, собирать команды, запускать проекты и формировать профиль достижений.

## Технологии

- iOS: SwiftUI, Observation, async/await.
- Backend: FastAPI.
- База данных: PostgreSQL 17.
- Локальный запуск backend и базы: Docker Compose.
- Авторизация: JWT, токен хранится в iOS Keychain.
- Защита сохранённой сессии: Face ID или код-пароль устройства.

Firebase в проекте не используется.

## Уже реализовано

- Регистрация и вход через email и пароль.
- Раздельные вход и регистрация через Google Sign-In.
- Гостевой режим с ограничением действий, требующих аккаунт.
- Главный экран возможностей, поиск и фильтрация по категориям.
- Экран подробной информации о возможности.
- ProjectHub, просмотр проектов и создание проекта.
- Отклики на роли, просмотр входящих заявок, принятие, отклонение и отмена.
- Удаление проекта владельцем и серверный API редактирования проекта.
- Профиль пользователя и настройки.
- Серверный профиль достижений с добавлением и удалением записей.
- Серверные закладки возможностей.
- Карта возможностей на данных Spark Backend.
- Тактильная обратная связь для основных успешных действий.
- Тёмная тема.
- Face ID с системным резервным сценарием.
- FastAPI API и PostgreSQL для пользователей, возможностей и проектов.
- Начальные данные возможностей и проектов.
- Базовые серверные и iOS-тесты.

## Конфигурация Spark Backend

- Симулятор: `http://127.0.0.1:8000/api/v1/`.
- Реальный iPhone в одной Wi-Fi сети с Mac: `http://MacBook-Air-YULIYA.local:8000/api/v1/`.
- Для временного переопределения при запуске можно использовать переменную окружения `SPARK_API_BASE_URL`.
- Backend должен слушать `0.0.0.0:8000`, а Docker Engine и контейнеры должны быть запущены.

## Ближайшие задачи

1. Проверить регистрацию и вход на реальном iPhone через локальную сеть.
2. Развернуть Spark Backend и PostgreSQL в интернете с HTTPS, чтобы приложение не зависело от включённого Mac.
3. Добавить экран редактирования проекта и управление составом ролей.
4. Добавить подтверждение email и восстановление пароля через почту.
5. Синхронизировать аватар профиля с сервером.
6. Добавить внутренний центр уведомлений.
7. Расширить unit- и UI-тесты на авторизацию, Keychain, Face ID и полный пользовательский сценарий.
8. Подготовить удаление аккаунта, политику конфиденциальности, TestFlight и App Store.

## Известные ограничения

- Без доступного Spark Backend регистрация, вход и загрузка серверных данных не работают.
- Локальный backend доступен реальному iPhone только в одной сети с Mac.
