# Spark — Текущее состояние проекта

## Идея проекта

Spark — мобильное приложение для студентов и молодых специалистов.

Цель: собрать в одном месте:

* Хакатоны
* Стажировки
* Гранты
* Конкурсы
* Волонтёрские программы
* Команды для проектов
* Мероприятия

Пользователь может искать возможности, фильтровать их по категориям и получать подробную информацию.

## Компоненты

### SparkButton

Кастомная кнопка.

Поддерживает:

* текст
* иконку
* разные цвета
* режим полной ширины
* компактный режим

### SparkTextField

Кастомное текстовое поле.

Поддерживает:

* иконку
* placeholder
* разные цвета
* secure режим

### CategoryChip

Фильтр категорий.

Поддерживает:

* выбранное состояние
* нажатие
* кастомный стиль

### ParticipantsView

Компонент с аватарками участников.

Используется внутри карточек мероприятий.

---

## EventCard

Полностью реализована карточка мероприятия.

Содержит:

* изображение
* статус
* бонус
* категорию
* название
* описание
* локацию
* дату
* участников
* кнопку "Подробнее"

Поддерживает:

* необязательный бонус
* необязательное количество участников
* разные цвета категорий

## Данные

Создана структура Event.

Создан массив mockEvents.

HomeView отображает карточки через:

ForEach(mockEvents)

Вся информация хранится централизованно.
