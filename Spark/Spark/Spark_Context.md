# Spark — текущее состояние проекта

## Концепция

Spark — цифровая экосистема развития молодёжи Беларуси. Приложение помогает находить возможности, собирать команды, запускать проекты и формировать профиль достижений.

## Технологии

- iOS: SwiftUI, Observation, async/await.
- Backend: FastAPI.
- База данных: PostgreSQL 17.
- Локальный запуск backend и базы: Docker Compose.
- Авторизация: JWT, токен хранится в iOS Keychain.
- Защита сохранённой сессии: Face ID или код-пароль устройства.

Firebase в проекте не используется.

## Конфигурация Spark Backend

- Симулятор: `http://127.0.0.1:8000/api/v1/`.
- Реальный iPhone в одной Wi-Fi сети с Mac: `http://MacBook-Air-YULIYA.local:8000/api/v1/`.
- Для временного переопределения при запуске можно использовать переменную окружения `SPARK_API_BASE_URL`.
- Для TestFlight и App Store production-адрес задаётся строковым ключом Info.plist `SparkAPIBaseURL`.
- Backend должен слушать `0.0.0.0:8000`, а Docker Engine и контейнеры должны быть запущены.

2. Выбрать хостинг и развернуть подготовленные Spark Backend и PostgreSQL в интернете с HTTPS.
3. Настроить production SMTP и отключить выдачу тестовых кодов подтверждения.
4. Расширить unit- и UI-тесты на авторизацию, Keychain, Face ID и полный пользовательский сценарий.
5. Опубликовать политику конфиденциальности по публичному HTTPS-адресу и добавить контакт поддержки.
6. Подготовить карточку приложения, подпись, архив и сборку TestFlight в Apple Developer Program.
7. Проверить социальные функции, публикацию и модерацию событий на устройствах с работающим backend.
8. Проверить порядок рассмотрения заявок организаций на устройстве и определить критерии подтверждения.
9. Внедрить отслеживаемые миграции базы; порядок применения текущих SQL-скриптов описан в `spark-backend/README.md`.
10. Проверить фильтры карты и сценарии публикации на устройстве.
11. Согласовать доступ к календарю Space Media: автоматический запрос сейчас получает защитную страницу; требуется официальный API, календарная лента или разрешённый способ интеграции.
12. Проверить новые социальные сценарии, локальные напоминания и рекомендации на устройствах; рассмотреть управление публичностью портфолио и push-уведомления.
13. Развить подбор: синонимы, обратная связь и, при необходимости, подключение модели с согласованным способом обработки данных и стоимостью.

## Известные ограничения

- Без доступного Spark Backend регистрация, вход и загрузка серверных данных не работают.
- Локальный backend доступен реальному iPhone только в одной сети с Mac.
